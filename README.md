# Code Playground

A small browser-based coding tool for experimenting with HTML, CSS, and JavaScript. Edit the three panels and click **Run** (or press **Ctrl/⌘ + Enter**) to see the result in the preview.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Features

- Separate HTML, CSS, and JavaScript editors
- Sandboxed live preview
- Starter example and reset button
- Responsive layout for mobile and desktop

The playground runs locally in your browser; it does not upload or save your code.
